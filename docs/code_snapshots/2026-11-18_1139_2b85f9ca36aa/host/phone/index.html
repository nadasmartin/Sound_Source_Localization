Sound bench speaker

The laptop decides what this phone plays. Leave this page open in front.

  • Set the media volume to the level you want to keep for the whole test (max is fine), and don't change it during a run.
  • Keep the screen on (raise the screen timeout); a locked phone stops playing.
  • iPhone: if you hear nothing, check the Ring/Silent switch and that no Bluetooth speaker/headphones are connected.
  • Turn off sound effects / equalizers / "Dolby" if the phone has them.
  • The speaker opening is the point you measure the position of.
