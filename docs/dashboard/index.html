    Measurement

    Metrics

    • 3D position error: |measured − true| per chirp; a point's value is the mean (p95 also given).
    • Direction error: angle between the measured direction (far-field solution, independent of the distance) and the true direction from the array centre; median per point.
    • Distance bias: median of |measured| − |true| (signed).
    • Success rate: accepted chirps / chirps played (20 per point).
    • Geometric sensitivity: distance std the geometry predicts for 1 µs independent timing noise on each mic (CRLB); ∞ exactly in a blind plane.
    • Fraunhofer distance: 2·D²/λ, λ at 7.5 kHz; D = side (and diagonal in the table).
    • Statistics use the newest placement of each point (a redo replaces the earlier one). All placements remain in the inspector.
